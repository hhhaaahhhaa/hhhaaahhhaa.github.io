This is a sample post. The first paragraph is used as the excerpt on the Blog tab.

To write a new post, add a file to `contents/blog/_posts/` named `YYYY-MM-DD-your-slug.md`
with a `title` in the front matter, then write Markdown below it. Images for the post go in
`contents/blog/your-slug/` and are linked as `/contents/blog/your-slug/photo.jpg`.
